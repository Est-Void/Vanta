# Vanta

Linux-ассистент в духе Copilot: ИИ-помощник, который не просто отвечает на вопросы, а **работает с вашей системой**. Запускает команды в терминале, управляет устройством, имитирует ввод мыши и клавиатуры, анализирует содержимое экрана и воспринимает голосовые команды.

```
┌───────────┐        HTTP/JSON + SSE
│   CLI     │──────────────┐
│  (vanta)  │              │
└───────────┘              ▼
                     ┌───────────┐
┌───────────┐  Unix  │   Демон   │      ┌───────────────┐

│(vanta-gui)│───────▶│           │      └───────────────┘
└───────────┘        └─────┬─────┘
                           │
        ┌────────┬─────────┼──────────┬──────────┐
        ▼        ▼         ▼          ▼          ▼
     Терминал  Устройство  Ввод     Экран      Голос
      (PTY)    (power/   (X11/    (скрин-    (STT/TTS)
               network)  Wayland)  шоты/OCR)
```

## Что это

Архитектура «демон + клиенты»: один процесс с привилегиями доступа к системе (**vantad**) обслуживает клиентов по Unix-сокету, а они обращаются к нему за работой с терминалом, устройством, экраном и голосом. Модель подключается плагином (сейчас — локальный Ollama).

## Возможности

- **Терминал и шелл-команды** — запуск команд, интерактивные PTY-сессии, стриминг вывода.
- **Шелл-интеграция** — «объясни команду», «исправь ошибку», пайп вывода в ассистента.
- **Управление устройством** — питание, сеть, аудио, дисплеи, процессы, пакеты.
- **Имитация ввода** — клавиатура и мышь через X11/Wayland и uinput.
- **Анализ экрана** — скриншоты, OCR/vision.
- **Управление окнами** — фокус, раскладка, виртуальные столы.
- **Анализ логов** — journalctl, диагностика ошибок.
- **Event-driven автоматизация** — правила-триггеры «условие → действие».
- **Голосовые команды** — STT/TTS.
- **Память и знания (RAG)** — семантический поиск по локальным документам.
- **Контекстная помощь** — знает систему, процессы и состояние файлов.

## Сборка и запуск

```bash
go build ./cmd/vantad ./cmd/vanta     # собрать демон и CLI

# нужен Ollama: https://ollama.com — и модель:
ollama pull llama3

vantad &                              # запуск демона
vanta status                          # проверить, что демон жив
vanta send "Привет, кто ты?"          # чат с моделью
```

Конфиг: `~/.config/vanta/config.toml` (токены, скоупы, URL и модель Ollama). При отсутствии файла используется dev-конфиг (`dev-token`, `llama3`). Токен CLI также берёт из переменной `VANTA_TOKEN`.
